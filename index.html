📌 PANDUAN PENGGUNAAN OBS STUDIO:

  1. Buka OBS Studio → Tambahkan Source baru bertipe Browser Source.
  2. Masukkan URL lokal overlay: file:///c:/Users/user/Downloads/Sponsor/overlay.html atau URL local server.
  3. Set resolusi ke Width: 1920 dan Height: 1080.
  4. Di Panel Kontrol (control.html), centang opsi "OBS Transparent" jika ingin latar belakang transparan menyatu dengan stream.
  5. Klik "TAMPILKAN" pada sponsor mana saja untuk melihat Mario melempar logo, atau klik "MAKAN" untuk memanggil Pacman!
